# PitWall Live V1

可直接部署到 GitHub Pages 的 F1 即時賽事伴侶網站原型。

## 功能
- 首頁下一場賽事與倒數
- LIVE Timing 順位、差距、輪胎、進站
- Live Map 示意
- Race Control
- 2026 賽程
- 車手 / 車隊積分榜
- 車手詳細頁
- PWA：可加入 iPhone 主畫面
- OpenF1 連線可用性檢查；沒有即時資料時自動以 Demo 資料呈現

## GitHub Pages
1. 建立新的 GitHub repository
2. 上傳此資料夾全部檔案到 repository 根目錄
3. Settings → Pages
4. Source 選 Deploy from a branch
5. Branch 選 main / root
6. 儲存後等待 GitHub Pages 網址產生
